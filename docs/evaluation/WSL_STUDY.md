verified version, completing the [CLI study](AGENT_STUDY.md) in an executable
read-only environment and establishing reliable real-repository observations.

evidence directory from official Node checksums and npm SHA-512-integrity-bound

command reports an existing ChatGPT login; the harness never reads, copies or

model and its shell scope is unavailable. No Mac task, worktree or config changed.

After the owner refreshed authentication with the official CLI, a separate
preflight completed one authorized file read with one paired command event,
matching final answer and reported usage, no capture errors and no policy
rejection. Neither preflight contributes a measured study sample.

The new study retains the five task families, two conditions, three repeats,
model gpt-6.1-sol, xhigh effort, seed, answer criteria, command budgets, historical
input evidence and separate blind grader. Execution is Ubuntu through WSL with
a Windows controller and C: mounted inputs, not a Linux-native storage benchmark.
Prompts use POSIX inspection rather than PowerShell; binary and data paths are
explicitly translated. This environment change is registered, not a retry added
to the old Windows measurement. Report its outcomes separately. Native test
evidence is the original Windows producer replay; no project tests are rerun.

Read-only sandbox, approval policy and existing execpolicy rules remain active.
No ignore-rules/bypass flag, alternate model, endpoint or copied token is used.
Coreutils timeout bounds the Linux process group to 290 seconds with a five-second
kill grace; the Windows controller also has a 300-second bound. CLI capture owns
exact argv, prompt, complete emitted JSONL, stderr, final answer and usage.
Malformed/missing/ambiguous turn data, error events, unpaired commands, mismatched
final messages and policy rejection withhold availability even after exit zero.
Captures prove emitted events, not hidden provider state or all OS actions.

Require a real read-only preflight before the thirty sequential sessions. Stop
at the first unavailable or noncompliant session, retain it without replacement,
and report incomplete collection rather than infer missing answers. Setup and
grading are separate costs. Provider usage is actual emitted usage, not billing
cost. Three repetitions cannot establish statistical significance or causal
productivity effects. Do not run the packet pilot concurrently with measured
agent sessions.
