# Isolated math repair observations

Completed collection and primary review on 2026-10-09. Both conditions produced
three correct repairs, three adequate source-bound answers and three workflows
within the registered read/edit boundary. All six passed eighteen withheld module
cases. Tool-arm elapsed median was lower on this case, while input accounting,
emitted command bytes and calls were higher. This is descriptive evidence from
three sessions per arm, not a general or causal efficiency benefit.

The [frozen protocol](REPAIR_MATH_PROTOCOL.md) owns conditions and scoring;
the [portable observations](REPAIR_MATH_OBSERVATION_2026-10-09.json) retain exact
samples, identities, counts and the separate primary audit. The [first replay](REPAIR_WORKFLOW_RESULTS.md)
is unchanged and is not pooled with this different case.

## Observed costs and interpretation

| Median, all three assigned available sessions | Conventional | Tool |
| --- | ---: | ---: |
| Completed command calls | 18 | 20 |
| Emitted command bytes, UTF-8 | 71,696 | 97,687 |
| CLI input tokens | 684,710 | 729,137 |
| CLI cached input tokens | 632,064 | 667,392 |
| CLI output tokens | 16,998 | 15,881 |
| CLI elapsed milliseconds | 736,737.38 | 635,211.81 |

Tool medians were 11.1% higher in calls, 36.3% higher in emitted bytes, 6.5%
higher in input accounting and 13.8% lower in elapsed time. These are CLI-emitted
accounting and controller wall times, not billing or complete context telemetry.
Small samples, different implementations/regression tests, tool-first paired
order and shared provider/cache state limit attribution. The first case showed
nearly equal elapsed medians with higher tool input/bytes; the cases support no
general token saving, correctness improvement or repository-wide speed claim.

Keep using bounded analyzers when their explicit evidence or interface matters.
This study does not justify requiring all four tools on every repair. Source
binding and declared-check acceptance complement selected behavioral tests and
maintainer review; they do not authenticate execution claims or establish every
application requirement. Node 22, macOS, Linux-native storage, full browser and
asynchronous revision acceptance remain unrun for this study.
