Use a tool only when its capability answers the current task. Read `capabilities` or `--help` first; retain the exact command, input snapshot, output and exit status as evidence. Unknown results require more evidence, not an invented pass or automatic retry.

For runtime/config questions, use Environment Doctor. For schema changes, use Contract Check. For deployment identity, collect bounded public/local evidence with Release Guard and then verify the normalized bundle. For supplied responsive geometry, focus and Back traces, use Runtime Trace's UI profile. These tools do not authorize writes, install dependencies, deploy applications, retry business operations or publish npm packages.

This skill is optional. No always-on hook or personal Codex configuration is installed. Follow the project's instructions and user's authorization; never change confirmation policies. See `docs/workflow/LOCAL_CLI.md` for source installation, PATH selection and rollback. Missing browser/cache evidence cannot establish installed-device PWA freshness.
